# Record who decided what, and at which revision {#record-who-decided-what-and-at-which-revision}

A review decision belongs to a pull-request review and the slide state it concerns. Viewed progress, comments, approval, requests for changes and withdrawal are distinct actions. Readers need both the decision and the context in which it was made.

Changing the reviewed explanation or code can make a prior decision out of date. Discussion has its own lifecycle and should remain traceable as the review evolves. Delegated actions retain provenance rather than pretending the assistant is the human reviewer.

Documentation authoring never grants a review verdict. Record a decision only when the reviewer explicitly asks for that action.
