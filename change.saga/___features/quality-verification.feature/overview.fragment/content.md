# Make verification inspectable {#make-verification-inspectable}

Test cases explain what is checked through preconditions, steps and expected outcomes. Evidence links a case to the criterion it verifies and the code that implements or exercises it. Run records retain the result, source commit, invocation and summary.

Readiness follows current relationships and verification policy. A result from another commit, a missing verification link or conflicting evidence cannot silently establish current confidence. Reading pages lead with the test definition and let a reader expand evidence and run history.

A recorded passing result is evidence of that execution. It is not an application-wide approval, and no new run is claimed unless it was actually performed.
