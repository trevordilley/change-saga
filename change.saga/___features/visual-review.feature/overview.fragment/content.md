# Discuss the explanation where it is shown {#discuss-the-explanation-where-it-is-shown}

Reviewers inspect a visual account of a change and attach context to the element being discussed. Comments and visual annotations keep a question beside the relevant diagram or code explanation instead of losing it in an unrelated thread.

Notes provide additional authored context. Surprise callouts explain behavior that could defeat a reasonable expectation. Deprecation annotations explicitly name content or exact code that should no longer be used, with a reason and optional replacement. These meanings should not be conflated.

Authoring an annotation does not approve the change. Discussion, viewed progress and review decisions remain separate, inspectable actions.
