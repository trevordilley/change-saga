# Coordinate delivery through explicit dependencies {#coordinate-delivery-through-explicit-dependencies}

Work items and ordered waves describe how a body of work is divided and integrated. Dependencies make blocked work visible. Versioned contracts identify the interface a dependent task is waiting for.

Append-only progress and integration evidence distinguish planned work from delivered work. A workspace reference locates the implementation effort; a merge record provides the concrete result. The plan can be queried without inferring completion from a branch name or a conversational promise.

A work plan coordinates delivery. It does not replace Product stories, the application design or verification evidence.
