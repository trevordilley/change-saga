# Read the application or inspect a change {#read-the-application-or-inspect-a-change}

Observation reads a chosen application state. Comparison asks what changed between a verified base and head, following Git history and the Saga records linked to that code. Readers can distinguish authored documentation changes from downstream impact.

A source reference is pinned to a commit and selection, so the same evidence can be inspected in later comparisons. Moved lines and changed bytes have different meanings. Record history explains when a definition changed without turning the current page into a chronological log.

Keep the selected repository and revisions visible. Missing or stale evidence remains a limitation, not a reason to guess a current explanation.
