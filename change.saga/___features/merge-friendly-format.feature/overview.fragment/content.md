# Keep knowledge reviewable in Git {#keep-knowledge-reviewable-in-git}

The Saga stores small, independently authored records and assets. Stable identity survives new definitions, moves and ordinary branch integration. Complete immutable revisions keep older intent inspectable.

Concurrent writers name observed parents and use public mutation commands. Independent additions can merge naturally; competing heads remain explicit conflicts. Lifecycle events preserve why a proposal was accepted, rejected or retired without overwriting its definition.

File publication is checked and cooperative, but multi-file writes are not a distributed transaction. The [storage essay](/technical/pages/storage) explains locks, staging, rollback and recovery boundaries.
