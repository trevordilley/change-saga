# Explain mechanisms with an authored technical account {#explain-mechanisms-with-an-authored-technical-account}

A feature implementation deck combines a detailed overview with ordered visual slides. The overview explains responsibilities, models, execution paths and tradeoffs; slides make those mechanisms easier to inspect. A short Front summarizes each slide, while its Back carries the detailed diagram.

Semantic Items connect visual elements to exact source evidence and, where appropriate, product intent. Diagrams can express flows, relationships, sequences, boundaries and surprises. A diagram should make a relationship visible rather than turn a list of filenames into boxes.

Application-wide design lives in the [approach essay and three whiteboards](/technical). Feature decks explain focused mechanisms, and review decks explain changes between commits.
