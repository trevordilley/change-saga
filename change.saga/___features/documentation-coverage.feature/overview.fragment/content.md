# See what an explanation leaves out {#see-what-an-explanation-leaves-out}

Coverage connects exact changed code to the targets that explain it. A missing mapping is an actionable omission; an overlapping or stale mapping needs inspection. Coverage complements reading the explanation and running tests.

Review coverage concerns one change. Living-documentation currency concerns whether an explanation still matches the application at the viewed head. A whiteboard source pin, deck overview citation or passing check does not substitute for exact Item evidence.

Reconciliation gives an ordered repair queue. Inspect the source change before accepting a proposed remap, and revise explanations that no longer hold. [Evidence and storage](/technical/pages/storage) describes the underlying model.
