# Visual implementation model {#visual-implementation-model}

An implementation deck is an ordered visual argument rather than a decorated file list. Each slide has one reviewer intent and takeaway, uses an SVG, raster image, or sandboxed HTML entrypoint, and identifies semantic Items inside the visual. Exact code evidence belongs to those Items so a reviewer can move from the system explanation to the responsible source without losing context.

The durable feature deck describes the application as it exists. A pull-request review uses the same visual vocabulary to explain a transition and its reasoning.
